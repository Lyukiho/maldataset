下面是刚才搜到的、与“IDA/Ghidra 反编译代码 + 语言模型 + 恶意检测”相关的论文地址。

最直接相关：

1. [A Decompilation-Driven Framework for Malware Detection with Large Language Models](https://arxiv.org/html/2601.09035v1)
   Ghidra 反编译 Windows PE，再由 LLM 判断良性/恶意。

2. [I-MAD: Interpretable Malware Detector Using Galaxy Transformer](https://arxiv.org/pdf/1909.06865)
   对反汇编代码进行“基本块—函数—PE”分层建模，实现可解释恶意检测。

3. [MALSIGHT: Exploring Malicious Source Code and Benign Pseudocode for Iterative Binary Malware Summarization](https://arxiv.org/html/2406.18379v3)
   使用恶意源代码和良性反编译伪代码训练 MalT5，对恶意函数进行自然语言摘要。
   [arXiv 摘要页](https://arxiv.org/abs/2406.18379)

4. [AsmRAG: LLM-Driven Malware Detection by Retrieving Functionally Similar Assembly Code](https://arxiv.org/html/2604.23196v1)
   函数级汇编代码嵌入、检索和恶意判断，强调可验证的恶意函数证据。

反编译伪代码建模：

5. [Extending Source Code Pre-Trained Language Models to Summarise Decompiled Binaries](https://arxiv.org/abs/2301.01701)
   提出 BinT5 和 CAPYBARA，包含约21.4万个反编译函数—文档对。
   [论文 PDF](https://arxiv.org/pdf/2301.01701)
   [代码与复现仓库](https://github.com/AISE-TUDelft/Capybara-BinT5)

6. [UPPC: Unleashing the Power of Pseudo-code for Binary Code Similarity Analysis](https://link.springer.com/article/10.1186/s42400-022-00121-0)
   使用 IDA Pro 7.5 提取函数伪代码和调用图，学习函数语义向量。
   [代码仓库](https://github.com/UnPPCode/uppc)

7. [CP-BCS: Binary Code Summarization Guided by Control Flow Graph and Pseudo Code](https://aclanthology.org/2023.emnlp-main.911/)
   同时利用伪代码、汇编和控制流图理解二进制函数。
   [论文 PDF](https://aclanthology.org/2023.emnlp-main.911.pdf)
   [arXiv](https://arxiv.org/abs/2310.16853)

8. [A Transformer-based Model for Decompiled Identifier Renaming](https://aclanthology.org/2021.nlp4prog-1.6/)
   使用 Transformer 恢复反编译代码中的变量名和标识符。
   [论文 PDF](https://aclanthology.org/2021.nlp4prog-1.6.pdf)

反汇编语言模型：

9. [PalmTree: Learning an Assembly Language Model for Instruction Embedding](https://arxiv.org/abs/2103.03809)
   在大量无标签汇编代码上预训练指令语言模型。
   [ACM 正式页面](https://dl.acm.org/doi/10.1145/3460120.3484587)

10. [Zero Day Ransomware Detection with Pulse: Function Classification with Transformer Models and Assembly Language](https://arxiv.org/html/2408.07862v1)
    将汇编指令看作词、函数看作句子，用 DistilBERT 等模型判断恶意函数和样本。

11. [MalwarePT: A Binary-Level Foundation Model for Malware Analysis](https://arxiv.org/html/2605.16455v1)
    对 Windows PE 代码节进行语言模型式预训练，支持函数能力分类和整文件恶意检测。

辅助理解与评估：

12. [Feasibility Study for Supporting Static Malware Analysis Using LLM](https://arxiv.org/html/2411.14905v1)
    把逐函数反编译/反汇编结果交给 LLM 解释，并由静态分析人员评价。

13. [Code is not Natural Language: Unlock the Power of Semantics-Oriented Graph Representation for Binary Code Similarity Detection](https://www.usenix.org/system/files/usenixsecurity24-he-haojie.pdf)
    讨论为什么不能简单把汇编当普通自然语言序列，强调控制流、数据依赖和调用约定。

如果只选最值得先看的五篇，我建议按这个顺序：

1. I-MAD
2. UPPC
3. BinT5/CAPYBARA
4. CP-BCS
5. Decompilation-Driven Malware Detection
